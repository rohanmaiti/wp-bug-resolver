## Bug card
- **Tenant / URL:** twos.wizcommerce.com header mega menu (header doc 11995 › ekit-nav-menu 2f5fed0) → /collection/day-dreamer/?sort=created_at*desc. Prod.
- **Expected vs actual:** Expected the Daydreamer collection listing. Actual: "404 Not Found – Oops, the page you requested does not exist."
- **Repro:** Open the site → Collections / Baby and Kids mega menu → Daydreamer (or open the URL directly).
- **Device / login:** Any device. Reproduced logged out (public).
- **Attachments:** 1 screenshot of the 404 (not viewed; reproduced live). Jira comment by Aryan Baliyan calls it a data issue. It isn't: the collection exists under another slug.

## Root cause
- **Not missing data.** `/collection/daydreamer/` returns 200 ("Daydreamer – Twos Company", listing + wiz_v2_product_grid), while `/collection/day-dreamer/` returns 404. The nav link has a typo'd slug.
- **The bad links are in Elementor icon-list widgets inside the mega-menu content docs (wp-post type):**
  - doc 7525 › icon-list #68199f6 (item "Daydreamer")
  - doc 25945 › icon-list #bfeca9a (item "Daydreamer")
- **A second broken link of the same kind (the ticket says other collections may be affected):** I fetched all 253 unique /collection/ and /category/ nav links and only two return 404: day-dreamer and the-charm-shop. `/collection/charm-shop/` returns 200 ("Charm Shop – Twos Company").
  - doc 7525 › icon-list #4f91f24 (item "The Charm Shop")
  - doc 25941 › icon-list #5b0a905 (item "The Charm Shop")

## Fix plan
