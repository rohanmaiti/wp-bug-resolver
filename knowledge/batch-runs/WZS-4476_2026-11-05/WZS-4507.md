## Root cause
Not confirmed live. The code (storefront-wp master, `widgets/account/orderHeader.php`) shows the order header renders two separate icon-only actions, both on by default:
- **Tearsheet Download** (`show_tearsheet_download`, `.wiz-order-header-tearsheet`) downloads the order document as PDF (or PDF + Excel). Its icon is document-with-arrow, and its `tearsheet_button_text` control defaults to empty ("Leave empty for icon only").
- **Download Media** (`show_download_media`, responsive switcher, default yes) opens the download-media modal for the order's product images. Its icon is the image/gallery icon. `render_header_download_media_button()` hardcodes `button_text => ''` (orderHeader.php ~L1120), so it has no label control.
So these aren't duplicates. They're two different downloads, shown without labels.
